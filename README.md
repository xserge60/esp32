# 🔔 ESP32 Telegram Doorbell (Умный звонок)

Простой и надежный умный дверной звонок на базе микроконтроллера **ESP32 D1 Mini** под управлением **MicroPython**. При нажатии на физическую кнопку звонка устройство моментально отправляет PUSH-уведомление в Telegram.

---

## 🛠 Особенности

* **Быстрая отклик:** отправка уведомлений через Telegram Bot API.
* **Безопасность данных:** конфигурация (данные Wi-Fi и токены) вынесена в отдельный JSON-файл и не попадает в публичный репозиторий.
* **Модульность:** написан на MicroPython с использованием удобного CLI-инструмента `mpremote`.
